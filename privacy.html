    개인정보 처리방침

    시행일: 2026년 9월 6일 · 버전 1.3

    한 문단 요약 — Runvis는 러닝·건강 데이터를 당신의 기기 안에서만 처리합니다. Runvis가 운영하는 서버는 없고, 계정도 없으며, 당신의 운동·건강 데이터를 개발자를 포함한 누구에게도 전송·판매·공유하지 않습니다. 아래에 그 예외 전부(날씨 조회, 애플 결제, 지도 경로 생성, 동네 이름 조회, 공개 코스·신발 목록 파일 내려받기, 사용자가 직접 누르는 러닝화 검색 링크)를 숨김없이 설명합니다.

    1. 수집·처리하는 데이터

    Runvis는 다음 데이터를 기기 내에서 읽고 처리합니다. 모두 앱 기능 제공 목적이며, 기기 밖으로 나가지 않습니다.

    • 운동 데이터: 심박수, 페이스, 거리, GPS 경로, 고도, 케이던스, 러닝 파워·보폭·접지시간·수직진폭(지원 기기), 칼로리 — Apple HealthKit을 통해 읽고 저장
    • 건강 데이터: 수면(시간·단계), 심박변이도(HRV), 안정시 심박, VO₂max, (선택 시) 월경 주기 — 훈련 준비도·회복 분석에 사용
    • 모션 데이터: 손목 가속도(러닝 자동 시작 감지), (착용 시) AirPods 머리 모션 — 폼 신호 참고용
    • 프로필 입력값: 출생연도, 성별, 안정시 심박수, 최대 심박수 — 첫 설정 화면에서 직접 입력하며, 심박 존과 나이 기반 추정의 기준으로만 씁니다
    • 그 밖의 입력 데이터: 목표 대회·기록, 코치 성향, 신발 정보, 운동 후 체크인(강도·통증·수분)
    • Bluetooth 센서: (연결 시) 심박 밴드, 사이클링 파워미터·스마트 트레이너의 실시간 측정값
    • 진단 데이터: 앱 크래시·응답 없음 리포트(Apple MetricKit) — 기기에만 저장되며, 사용자가 직접 공유(내보내기)할 때만 기기 밖으로 이동합니다

    2. 데이터가 저장되는 곳

    • 운동 기록·경로는 Apple 건강(HealthKit)에 저장됩니다 — 소유자는 당신이며, iCloud 건강 동기화 여부는 iOS 설정을 따릅니다
    • 앱 설정·프로필 입력값·플랜·코스·배지 계산 결과는 기기 내 앱 저장공간에만 저장됩니다
    • Runvis는 자체 서버·데이터베이스·계정 시스템을 운영하지 않습니다
    • Runvis는 자체 백업·동기화를 하지 않습니다. 기기를 바꾸면 Apple 건강에 저장된 운동 기록은 따라오지만, 프로필·신발·플랜·배지와 코치가 만든 기준선처럼 앱 저장공간에만 있는 값은 따라오지 않습니다

    3. 기기 밖으로 나가는 예외 (전부)

    예외전송되는 것받는 곳
    날씨 브리핑약 1km 단위로 반올림한 대략적 좌표(동네 수준 정밀도)와 시각 — 요청 순간에만, 저장·식별자 없음Open-Meteo(무료 기상 API)
    구독 결제결제 처리 전부 — Runvis는 카드·결제 정보를 보지도, 저장하지도 못합니다Apple App Store
    코스 자동 생성경로 계산용 현재 좌표 — 생성 요청 순간에만(반올림하지 않은 값)Apple 지도(MapKit)
    동네 이름 표시날씨 브리핑과 운동 기록에 "역삼동" 같은 동네 이름을 붙이기 위한 현재 좌표 — 조회 순간에만, 반올림하지 않은 값. 결과는 기기에 캐시되어 같은 장소는 다시 조회하지 않습니다Apple 위치 서비스(CLGeocoder)
    코스·신발 목록 내려받기보내는 데이터 없음 — 공개된 파일을 하루 한 번 익명으로 내려받기만 합니다(웹사이트 방문과 동일하게 접속 IP는 노출)GitHub Pages(정적 파일 호스팅)
    새 러닝화 검색 열기보내는 데이터 없음 — 워치의 신발 화면에서 사용자가 버튼을 직접 눌렀을 때만, 검색어 "러닝화"가 들어간 주소로 외부 브라우저가 열립니다. 운동·건강 데이터나 신발 기록은 함께 나가지 않습니다외부 쇼핑몰(현재는 한국 쇼핑몰 쿠팡의 검색 페이지)

    위 경우 모두 이름·이메일 등 식별 정보는 포함되지 않으며, Runvis가 별도로 기록하지 않습니다. Runvis는 수집·기록한 운동·건강 데이터를 업로드하지 않습니다 — 앱에는 이를 업로드하는 코드가 없으며, 위 통신은 조회에 필요한 최소 정보만 담은 읽기(조회) 요청입니다.

    4. 권한 사용 목적

    • 건강(HealthKit): 운동 기록 저장·과거 기록 분석
    • 위치: 러닝 경로 기록, 날씨 브리핑, 코스 안내
    • 모션: 달리기 시작 자동 감지, 준비운동 안내
    • 알림(선택): 훈련 플랜 요일 알림, 저녁 브리핑, 일요일 주간 코치 요약, 오랜만의 복귀 안내, 구독 갱신 이틀 전 안내 — 알림 문구는 기기 안에서 만들어지며 서버로 전송되지 않습니다
    • Bluetooth: 외부 센서(심박 밴드·파워미터) 연결
    • 캘린더(선택): 훈련 플랜 일정 추가
    • 사진(선택): 경로 플라이오버 영상 저장

    모든 권한은 거부해도 해당 기능 외의 앱 사용에는 지장이 없습니다.

    5. 제3자 제공·광고·추적

    • 제3자 제공: 없음 — 앱이 처리하는 운동·건강 데이터 기준입니다. 유일한 예외는 웹사이트 베타 신청 이메일의 처리 위탁(Formspree)으로, 아래 6절에서 설명합니다
    • 광고 SDK·분석 SDK·추적 도구: 없음
    • 데이터 판매: 없음

    6. 웹사이트(베타 신청)

    홈페이지(runvis.app)의 베타 신청 폼으로 이메일 주소를 제출하는 경우 아래와 같이 처리됩니다. 이 절은 웹사이트 폼에만 적용되며, 앱은 이메일을 포함해 어떤 계정 정보도 수집하지 않습니다.

    • 수집 항목: 이메일 주소(신청자가 직접 입력한 것에 한함)
    • 수집 목적: TestFlight 베타 초대장 발송과 베타 진행 관련 안내
    • 처리 위탁·국외 이전: 폼 전송·보관은 Formspree, Inc.(미국)의 폼 처리 서비스에 위탁되며, 제출한 이메일은 Formspree 서버(미국)에 전송·보관됩니다 — Formspree 개인정보 처리방침
    • 보관·파기: 베타 초대 발송 등 수집 목적 달성 시 지체 없이 파기하며, 늦어도 수집일로부터 1년 이내 파기합니다. 삭제 요청: help@runvis.app

    7. 데이터 삭제

    앱을 삭제하면 앱 저장공간의 데이터(프로필 입력값 포함)가 삭제됩니다. HealthKit에 저장된 운동 기록은 당신 소유이므로 앱 삭제 후에도 건강 앱에 남으며, 건강 앱에서 직접 삭제할 수 있습니다.

    8. 아동

    Runvis는 만 14세 미만을 대상으로 하지 않습니다. 심박 존과 나이 기반 추정을 계산하기 위해 첫 설정에서 출생연도를 입력받지만, 이 값은 기기 안에만 저장되며 외부로 전송되지 않습니다. 가족 공유 구독으로 자녀가 사용하는 경우 보호자의 지도가 필요합니다.

    9. 의료 면책

    Runvis의 모든 수치와 안내는 공개된 운동과학 공식에 기반한 참고용 추정치이며, 의학적 진단·치료·처방이 아닙니다. 흉통·어지럼 등 이상 증상이 있으면 즉시 운동을 중단하고 전문가와 상담하세요.

    10. 변경 및 문의

    방침이 바뀌면 이 페이지의 시행일을 갱신합니다. 이용약관은 이용약관을 참고하세요. 문의: help@runvis.app
